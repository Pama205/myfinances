# Finanzas Familiares

[![CI/CD](https://github.com/tu-usuario/finanzas-familiares/actions/workflows/ci-cd.yml/badge.svg)](https://github.com/tu-usuario/finanzas-familiares/actions/workflows/ci-cd.yml)

## Descripción

Esta aplicación web te permite gestionar las finanzas de tu familia de forma sencilla y eficiente. 

**Funcionalidades:**

* Registrar ingresos y gastos.
* Categorizar transacciones.
* Controlar deudas y ahorros.
* Gestionar inversiones.
* Agregar cuentas bancarias.
* Convertir dólares a bolívares con la tasa de cambio actual.
* Generar reportes y gráficos.
* Autenticación de usuarios.

## Tecnologías

* **Backend:** Node.js, Express.js
* **Frontend:** Next.js, React
* **Base de datos:** MongoDB (o la que elijas)
* **Contenedores:** Docker, Docker Compose
* **CI/CD:** GitHub Actions

## Instalación

1. Clona el repositorio: `git clone https://github.com/Pama205/myfinances.git`
2. Navega a la carpeta del proyecto: `cd myfinances`
3. Instala las dependencias (backend y frontend): 
    * `cd backend && npm install`
    * `cd frontend && npm install`
4. Configura las variables de entorno (ver `.env.example`).
5. Ejecuta la aplicación con Docker Compose: `docker-compose up -d`

## Uso

1. Accede a la aplicación en tu navegador: `http://localhost:3001`
2. Crea una cuenta de usuario.
3. Empieza a registrar tus transacciones.
